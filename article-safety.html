অনলাইনে নিরাপদ থাকার ১০টি গুরুত্বপূর্ণ নিয়ম

Online account নিরাপদ রাখতে শুধু password যথেষ্ট নয়। Login alert, two-factor authentication, app permission এবং phishing সম্পর্কে সচেতন থাকাও গুরুত্বপূর্ণ।

১. প্রতিটি গুরুত্বপূর্ণ account-এ আলাদা password

এক password একাধিক জায়গায় ব্যবহার না করাই ভালো। সম্ভব হলে password manager ব্যবহার করে দীর্ঘ ও আলাদা password রাখুন।

২. Two-factor authentication চালু করুন

যে service 2FA বা passkey support করে সেখানে available security option চালু করুন।

৩. OTP বা recovery code কাউকে দেবেন না

Support পরিচয় দিলেও OTP, password বা recovery code শেয়ার করবেন না।

৪. Link খোলার আগে domain দেখুন

Message বা email-এর link-এ click করার আগে domain spelling এবং website address যাচাই করুন।

৫. App permission পরীক্ষা করুন

কোনো app অপ্রয়োজনীয়ভাবে contact, microphone, location বা storage access চাইলে প্রয়োজনীয়তা যাচাই করুন।

৬. Software update রাখুন

Device ও গুরুত্বপূর্ণ app-এর security update available হলে trusted source থেকে install করুন।

৭. Public device-এ account ব্যবহার করলে logout করুন

Shared computer বা অন্যের device-এ login করলে কাজ শেষে sign out করুন এবং saved password আছে কি না পরীক্ষা করুন।

৮. Login alert দেখুন

অচেনা login বা security notification পেলে account-এর recent activity পরীক্ষা করুন এবং প্রয়োজন হলে password পরিবর্তন করুন।

৯. Backup রাখুন

গুরুত্বপূর্ণ ছবি ও documents-এর প্রয়োজনীয় backup রাখলে device হারানো বা নষ্ট হওয়ার ঝুঁকি সামলানো সহজ হয়।

১০. সন্দেহ হলে থামুন

অস্বাভাবিক prize, urgent payment request বা account বন্ধ হওয়ার ভয় দেখানো message পেলে তাড়াহুড়ো না করে official channel দিয়ে যাচাই করুন।

শেষ কথা

Online safety নিয়মিত অভ্যাসের বিষয়। আপনার account ও device-এর security settings সময় সময় review করুন।
