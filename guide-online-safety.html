Online Safety: নিরাপদ থাকার ৫টি গুরুত্বপূর্ণ গাইড

১. শক্তিশালী password

প্রতিটি গুরুত্বপূর্ণ account-এর জন্য আলাদা password ব্যবহার করুন। সহজে অনুমান করা যায় এমন নাম, জন্মতারিখ বা একই password বারবার ব্যবহার করা এড়িয়ে চলুন।

২. Two-factor authentication

যেসব service 2FA দেয় সেখানে এটি চালু করা account security বাড়াতে সাহায্য করে। Backup codes নিরাপদ জায়গায় রাখুন।

৩. Phishing চিনবেন কীভাবে

অচেনা message-এর urgent language, সন্দেহজনক domain, ভুল বানান বা অস্বাভাবিক login link দেখলে সতর্ক হন। Link-এ যাওয়ার আগে domain পরীক্ষা করুন।

৪. Public Wi-Fi

Public network-এ sensitive কাজ করার সময় সতর্ক থাকুন। অচেনা network-এ automatic connection বন্ধ রাখা এবং গুরুত্বপূর্ণ service-এ secure connection ব্যবহার করা ভালো অভ্যাস।

৫. App ও browser update

Official source থেকে software update রাখুন। Browser ও operating system-এর security update পুরোনো হলে পরিচিত vulnerability-এর ঝুঁকি বাড়তে পারে।

English summary

Basic online safety starts with unique passwords, two-factor authentication, phishing awareness, careful public Wi-Fi use and timely software updates.
